The game is called quadspace
It's a browser based game

Style:
Neon, 80s arcade style with a futuristic twist.
2D square area, with "space" themed background almost like a depth field.

Game: 
You are a ship that can shoot up down left right. 
You can move any direction on a flad 2d plane in the x and y axis.
metallic spheres roughly the same size as the ship spawn from random edges of the plane and persist within the plane until destroyed by a shot from the ship
The spheres have a constant velocity, and bounce at a 90 degree angle of incidence against the place walls.

Details:
You get 8 points for destroying a sphere.
Each level the amount of spheres to destroy is 8*level number.
The sphere spawn rate increases by 1 per second each round. eg round 1 is 1 per second. round 2 is 2 per second
There can be an fast animation of the sphere shringing and disappearing when shot.
The ship can move faster than the spheres however is a constant value.
There will be a display for the current score.
Each level will be introduced by the level number.
There will be a display for the current level.
The home page will be the list of the top ten high scores and will emulate a retro 80s arcade experince.
When game ends you can enter a name (max 50 chars) to store the score.
The top 100 file is checked and the score is inserted in order if greater than any score.

Technical:
ship movement = wasd on keyboard, or controller Left stick
fire shot = up, down, left, right on keyboard or a x b y con controller.
background music can be toggled on or off.
background music will be a catchy beat style either from a loop or a generated audio.

Other:
There is no authentication.
Scores will be kept in daily files named by date and scores will be ordered by date.
A single file for the higest 100 scores.
